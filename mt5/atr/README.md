# mt5/atr — вероятность сделки по истории (для агента «Трейдер (демо)»)

Положить в репозиторий `ostatki` в папку `mt5/atr/`:
- `atr_context.py` — инструмент для агента
- `atr_prob_table.json` — таблица вероятностей (9 инструментов: EURUSD, GBPUSD, USDCHF, USDCAD,
  AUDUSD, NZDUSD, EURGBP, USDJPY, XAUUSD; 5-мин история 2010/2012 — 25.11.2026)
- `probs.py` — как посчитана таблица (нужны данные и backtest.py из Downloads/backtest на Mac)

Запуск (нужно `pip install dukascopy-python pandas`):
```
python mt5/atr/atr_context.py                              # ATR и растяжение по всем инструментам
python mt5/atr/atr_context.py XAUUSD buy 3530 3510 3560     # P(TP раньше SL) для сделки
python mt5/atr/atr_context.py --signals mt5/signals.csv     # проверить все сигналы файла
```
P(TP раньше SL) — доля таких же сделок в истории: тот же SL в дневных ATR, тот же R:R,
то же «растяжение» движения. Почти везде ≈ безубыточности 1/(1+R:R): это реалистичная база,
а не сигнал. Цены BID, спред не учтён. Учебная торговля на демо-счёте, не инвестиционный совет.

## Эксперимент «ATR-тест», режим 90%+ (atr_strategy.py)
`python mt5/atr/atr_strategy.py` — каждый запуск берёт свежие 5-мин свечи (Dukascopy, 20 дней), заново считает
дневной ATR (среднее 5 последних полных дней) и ноги движения по XAUUSD, EURUSD, GBPUSD, USDJPY на двух уровнях
(50% и 100% дневного ATR, как в ноутбуке; 25% убран 25.11.2026 — спред съедает маленькую цель) и печатает строки для `mt5/signals.csv`, если за последний час
сработало правило: цена прошла 1A от начала ноги → вход по движению.

По требованию владельца вход только с исторической вероятностью TP ≥ 90%: SL = 3A, TP = 0.1–0.3A
(подобрано по 2010–2026 для каждого инструмента и уровня, таблица PARAMS в скрипте).

| Уровень | Риск | P(TP раньше SL) | После спреда |
|---|---|---|---|
| 50% | 0.5% | 91.4–94.6% | −0.03…−0.05R, PF 0.41–0.65 |
| 100%D | 0.5% | 90.3–94.3% | −0.01…−0.02R, PF 0.72–0.91 |

**Фильтр «тренд + сессия» (с 25.11.2026):** покупки только при вчерашнем закрытии выше SMA50 дневных закрытий,
продажи — только ниже; вход только 03:00–12:00 по Нью-Йорку (13:00–22:00 Ташкента зимой). На истории
2019–2026 PF 0.59 → 0.67 (2010–2018: 0.56 → 0.58), сделок примерно вдвое меньше. Прибыльной стратегию не делает.

Почему так: 90% попаданий возможны только с целью в 10–30 раз меньше стопа; один стоп съедает 10–30 тейков,
а спред съедает часть маленькой цели. Это проверка вживую на демо-счёте, а не прибыльная стратегия.

`atr_prob_table.json` содержит и маленькие R:R (0.05–0.75), поэтому `atr_context.py` считает P и для сделок с целью
меньше стопа.

## Лестница: одна сделка = 6 ордеров (ladder.py, с 25.11.2026)
L1 — по рынку (или по цене сигнала), L2…L6 — лимитки против движения с шагом 1/10 расстояния «вход → стоп»
(L6 — на полпути к стопу). Стоп и цель общие. Риск сделки делится на 6 (0.5% → 0.083% на ордер, 1% → 0.167%):
если стоп заберёт все шесть, убыток = прежний риск сделки. Правило 90% проверяется по L1; у дальних ордеров
вероятность TP ниже (цель дальше), но и прибыль больше.
```
python mt5/atr/ladder.py 20261125-1315-EURUSD EURUSD sell 1.0942 1.0992 1.0937 1 market "Комментарий"
```
id ордеров: `<база>-L1 … <база>-L6`, у ATR-теста `…-СИМВОЛ-S-L1-ATR50`.
⚠️ У золота при широком стопе лот одного ордера может выйти меньше минимального 0.01 — проверить по логу советника.
