# Остатки на складах

Страница остатков и цен по складам: https://kobiljonovulugbek-cmd.github.io/ostatki/

## Как обновлять остатки и цены со страницы
1. GitHub → аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
   - Repository access: Only select repositories → ostatki
   - Permissions → Repository → Contents: Read and write
   - Скопируйте ключ (начинается с github_pat_).
2. На странице нажмите «Вход для владельца» внизу и вставьте ключ.
3. Загружайте Excel/Word с остатками и меняйте цены. Остальные увидят изменения через 1–2 минуты.

Ключ хранится только в вашем браузере. Никому его не отправляйте.
